The datasets analyzed during the current study are publicly available at: 
    • BUS-CoT dataset: https://figshare.com/articles/dataset/A_Chain-of-thought_Reasoning_Breast_Ultrasound_Dataset_Covering_All_Histopathology_Categories/29036876/1?file=59014450 
    • BUS-BRA  dataset:  https://www.kaggle.com/datasets/orvile/bus-bra-a-breast-ultrasound-dataset 

After you download the datasets from the links above, insert the images folders inside the pre-existing data folder.
